# 调研与设计依据

这里回答「这套工作流为什么这样设计」，面向维护者和想理解取舍的人。开设普通项目时不需要拖动。

- [`../工作流完善调研与实施计划.md`](../工作流完善调研与实施计划.md)：记录 Superpowers、GitHub Spec Kit、Aider、AGENTS.md、ADR 等项目的调研结果，以及项目契约、可信基线、建议裁决、知识回流的设计依据。
- [`../项目契约模板.md`](../项目契约模板.md)：把调研结论转成项目可填写字段的契约模板。
- [`../项目适配与契约初始化工作流.md`](../项目适配与契约初始化工作流.md)：把调研结论转成首次进入项目时的调查、提问和确认流程。

调研文档里出现的项目用于说明设计灵感，不代表它们参与维护或背书本仓库。复制任何外部代码、CSS 或组件前，都要按来源逐项核验当前许可。
